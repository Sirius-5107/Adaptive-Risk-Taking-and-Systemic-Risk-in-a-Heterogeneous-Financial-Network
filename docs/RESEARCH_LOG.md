# Research Log

## 2026-10-01 — Project initialization
### Direction
Shifted from a generic financial risk-prediction / ML / portfolio-optimization project toward heterogeneous financial networks, systemic risk, clearing/contagion, and adaptive risk-taking.

### Rationale
This direction gives a clearer mathematical research question and is closer to the research themes motivating the project.

### Role of ML
ML is optional and secondary. The core contribution is a transparent, validated computational investigation.

### Working hypothesis
Adaptive incentives may create a gap between individually attractive risk-taking and collectively desirable system stability.

This is a hypothesis, not a predetermined conclusion.
