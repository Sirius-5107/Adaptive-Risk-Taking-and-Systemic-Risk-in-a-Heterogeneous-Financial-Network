# Limitations

1. The network is simulated rather than an observed financial network.
2. Balance sheets are highly simplified.
3. The clearing mechanism is inspired by payment-clearing ideas but is not a full reproduction of published clearing theory.
4. The shock process has only two risky-return states.
5. Independent random graphs are not realistic descriptions of all financial networks.
6. Risky versus conservative behaviour is highly compressed into a single risky-asset fraction.
7. Adaptive behaviour is a simplified rule rather than a full behavioural model.
8. τ=0.30 is arbitrary and must be sensitivity-tested.
9. Finite networks do not establish large-N theorems.
10. ML trained on simulated data primarily learns behaviour of the simulator.
11. Any optimization result is only as meaningful as its objective, constraints, and search space.
12. The one-week project window favours a small, validated computational model rather than a complete financial-network theory.

These limitations should be shown in the presentation, not hidden.
