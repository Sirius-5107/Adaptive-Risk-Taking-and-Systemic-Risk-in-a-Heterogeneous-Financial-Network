# Phase 3 — One Complete Stochastic Simulation

## Goal

Connect the Phase 2 heterogeneous network to institution balance sheets, an external risky-asset shock, and the Phase 1 payment-clearing solver.

Pipeline:

    network -> balance sheets -> risky-asset shock -> payment clearing -> default fraction

This is the first point where the project produces a complete system-level simulation rather than an isolated network or deterministic clearing example.

## Institution balance sheets

For the baseline run every institution starts with:

- external assets: 1.00
- external liabilities: 0.50
- interbank obligations: generated by the Phase 2 network

This is intentionally homogeneous at this stage. Heterogeneity currently enters through network connections and risky-asset exposure.

## Risk-taking

Group 0 is the lower-risk group and uses risky-asset fraction q_low = 0.20.

Group 1 is the higher-risk group and uses q_high = 0.60.

The risky asset has two possible returns:

- high return: 1.10
- low return: 0.70
- probability of low return: 0.20

For a low-risk institution in the bad state:

    A' = 1.00 * (0.80 + 0.20 * 0.70) = 0.94

For a high-risk institution:

    A' = 1.00 * (0.40 + 0.60 * 0.70) = 0.82

So the model creates a controlled difference in private exposure to the same external shock.

## Reproducibility

simulate_once(seed=...) uses one top-level seed and derives independent random streams for:

1. network generation
2. risky-return realization

The same seed reproduces the complete simulation exactly.

## What this phase does not claim

This is a computational model, not a calibrated representation of the real financial system.

In particular:

- all external assets and liabilities are still identical;
- all active interbank exposures have the same size;
- risky returns are independent two-state draws;
- the network is synthetic;
- there is no adaptive strategy change yet;
- there is no Monte Carlo estimate yet.

## Validation

Tests cover:

- reproducibility;
- risky exposure produces the expected asset loss;
- zero risky exposure leaves assets unchanged;
- invalid group labels are rejected;
- complete simulations converge;
- payment fractions stay in [0, 1];
- stronger adverse shocks do not increase post-shock assets.

## Next phase

Phase 4 will repeat this complete simulation many times and estimate systemic-failure probability with Monte Carlo uncertainty.
